# Sarosh's Hockey — Godot version

**How to open:** in Godot 4 (4.3 or newer), click **Import**, pick the `project.godot` file in this folder,
then press **▶ (Run Project)** at the top right (or F5).

The first time it opens, Godot imports `models/player.glb` (the real 3D person). That can take a minute.

**Controls:** W A S D skate · SHIFT sprint · SPACE shoot · R get the puck back

**Slow?** In `main.gd`, set `FANCY_LIGHTING := false`.
